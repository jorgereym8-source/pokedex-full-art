# Pokédex Full Art

App web (PWA) para seguir las cartas **Illustration Rare**, **Special Illustration Rare** y **Trainer/Galarian Gallery** de cada Pokémon de la Pokédex nacional.

- **Pokédex**: los Pokémon que tienen alguna de estas cartas, con filtros por generación, rareza y estado (conseguidos / me faltan).
- **Mi colección**: marca las cartas que tienes; el Pokémon queda como conseguido y se genera un listado con la imagen y los datos de cada carta y su valor estimado.
- **Compra**: lista de cartas que quieres comprar con su precio de Cardmarket (tendencia y desde), precio propio opcional y total.

Los datos se guardan en el navegador del dispositivo (con copia de seguridad exportable).

Fuentes: [pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data), [TCGdex](https://tcgdex.dev) (precios de Cardmarket), [PokéAPI](https://pokeapi.co) (nombres y sprites).
